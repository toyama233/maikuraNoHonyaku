## 概要

Minecraft の GUI 上に表示されるテキスト（クエスト文・本の文章など）を取得し、
外部翻訳サービスを用いて動的に翻訳することを目的とした実験的 Mod です。

通常の言語ファイルでは翻訳できない GUI コンポーネントを対象としています。

対応環境:

- Minecraft: 1.21.1
- Mod Loader: NeoForge

---

## 実装方針

### 非公式翻訳 API の使用

公式の翻訳 API では ID / パスワード等の設定が必要になるため、
導入の手間を減らす目的で **非公式の翻訳エンドポイント** を使用しています。

これにより、Mod フォルダに配置するだけで動作する構成にしていますが、
以下のリスクを伴います。

- 予告なく仕様変更・使用不可になる可能性がある
- 利用規約上の保証が存在しない
- 将来的な継続動作は保証できない

---

### 非同期処理による翻訳実行

クエスト画面や本を開いた際に翻訳処理を同期で行うと、
描画や操作に遅延が発生する可能性があるため、
翻訳リクエストは非同期で実行する構成としています。

ゲームにおいてはマップ読み込み等を除き、
基本的に非同期処理が望ましいと判断したためです。

## 開発中に直面した問題と対応

### 1. Java 経験不足

Java は大学の授業で基礎を学んだ程度の状態から開始しており、
不明点は調査および AI の支援を受けながら理解を進めました。

Mod 環境・非同期処理・HTTP 通信・JSON 解析などを
実装しながら学習する形になっています。

---

### 2. 翻訳 API 接続方式の変更対応

最初は別の HTTP ライブラリを使用していましたが、
数日後に突然通信できなくなる事象が発生しました。

最終的に Apache 系ライブラリに切り替えたところ、
現在は安定して通信できています。

また、エンドポイントから返却される JSON の形式が
途中で変化した可能性があり、
旧形式・新形式の両方をパースできるよう分岐処理を実装しています。

さらに、BAN 対策として以下を実装しています。

- 同一文章を再送信しないキャッシュ機構

---

### 3. GUI テキスト取得の困難さ

通常の API ではクエスト文や本の GUI テキストを取得できなかったため、
最終的に `drawInBatch` へのフックによって文字列を取得しています。

当初はログに Lambda 表現のような出力が表示され、
取得に失敗していると誤認していましたが、
実際にはそれが描画対象のテキストであることが判明しました。

複数行の描画をまとめるために StringBuilder を使用し、
実際の文章として再構成しています。

---

### 4. 翻訳対象のフィルタリング

一部 Mod では毎秒異なる文字列が描画されるため、
すべてを翻訳すると短時間で翻訳サービス側の制限に達する可能性があります。

しかし、描画処理は多くの Mod が同一経路を通過するため、
単純な呼び出し元判定では区別できませんでした。

そのため以下の方式を採用しています。

- スタックトレースを取得
- 経由クラスを判定して翻訳対象 Mod を制御
- ログ出力用ブラックリストを作成しノイズ除去

これにより、対象としたい GUI テキストのみ翻訳可能になっています。

---

## 現在の制限事項

- drawInBatch では行単位でしか取得できず、
  本などの文章単位での結合判定が困難
- 一部 GUI は正確に文章境界を判定できない
- 他 Mod との競合可能性あり

文章結合の改善方法については方針案はあるものの、
現時点では検証未実装のため未対応としています。
